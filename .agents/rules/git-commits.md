# Git Commit Conventions

Always format git commit messages using **V3 verb forms** (past tense / past participle) rather than V1 (imperative / base form):

- Use `fixed:` or `bug fixed:` instead of `fix:` or `bug fix:`
- Use `added:` instead of `add:`
- Use `updated:` instead of `update:`
- Use `resolved:` instead of `resolve:`
- Use `implemented:` instead of `implement:`
- Use `removed:` instead of `remove:`
- Use `refactored:` instead of `refactor:`

### Examples
- `fixed: resolved login error handling and auto-cleared input state`
- `updated: changed browser title icon from blue to golden yellow gradient`
- `added: implemented demo accounts and seed script for production database`
